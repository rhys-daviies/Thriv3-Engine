# A7.28 — academic recruitability shadow flag validation

**Shadow / read-only. No ranking, Recruitability, Pursuit, gate, Candidate G, `majorFit`, Financial
or Opportunity change.** Production remains `0ae0399`.

**Headline: the flag works, with zero false positives and one systematic error.** Against blind
recruitment judgement on 17 cards the two-level output separates **perfectly** — 13 true positives,
**0 false positives**, 4 true negatives, 0 false negatives. The single-level output misses three,
and all three miss for the same reason: a fixed shortfall cut, where the evidence says the shortfall
that warrants a question should shrink as selectivity rises.

---

# 1. The shadow assessment

Two independent outputs, because **evidence state is not concern state**.

**Evidence** — what we hold about the *joint* condition:

| | meaning |
|---|---|
| `MEASURED` | both the shortfall and the acceptance rate are known |
| `PARTIAL` | exactly one of them |
| `UNSCOREABLE` | neither |

**Outcome** — what that evidence suggests:

| | meaning |
|---|---|
| `NO_MATERIAL_CONCERN` | the evidence we hold gives no reason to check first |
| `ACADEMIC_REVIEW` | worth raising with the coach early |
| `PRE_READ_RECOMMENDED` | check academic admissibility before treating this as straightforwardly recruitable |
| `INSUFFICIENT_EVIDENCE` | a statement about us, not about the programme |

`MEASURED + NO_MATERIAL_CONCERN` and `MEASURED + PRE_READ_RECOMMENDED` are both ordinary results,
and they occur 3,740 and 338 times respectively across the 56 runs.

**What it refuses to claim**, asserted in the code and not only in prose: no admission probability,
no claim of rejection, no ineligibility, no "the coach cannot recruit this athlete", no removal.

The joint condition lives in `server/scripts/a728ShadowFlag.js` and nowhere else. Nothing imports
it. It annotates a ranking it does not touch.

## The boundary, and where it came from

Derived from the **twelve MEASURED cards of the A7.27 blind review**, frozen in
`A7.27-academic-cases.review.json` before this file existed:

```
acceptance >= 0.50            -> clears, whatever the shortfall
selective, shortfall >= -50   -> clears
selective, -350 < gap < -50   -> ACADEMIC_REVIEW
selective, gap <= -350        -> PRE_READ_RECOMMENDED
```

**The 0.50 clearing cut was declared under-determined before it was tested.** A7.27 observed
selective cases at 4.5–26% acceptance and clearing cases at 78–95%, and **nothing between 26% and
78%**. 0.50 is a midpoint, not a measurement — so the A7.28 pack was deliberately concentrated in
that gap.

# 2. A7.27 reproduction

**The shadow reproduces all 15 frozen A7.27 verdicts, including both selectivity traps and all
three evidence states.** 15/15, no disagreements. (This is partly construction — the boundary was
derived from twelve of those cards — which is why the out-of-sample test in §5 is the real one.)

Against A7.27's diagnostic *region* (shortfall ≥300 **and** acceptance <20%) the shadow is a
different rule and behaves differently, as expected:

| | A7.27 region | shadow `PRE_READ` |
|---|---:|---:|
| top-100, summed over 56 runs | 204 | **338** |
| top-25, summed over 56 runs | 84 | 122 |

The 134 extra flags decompose cleanly:

| acceptance band | shadow flags | also inside the A7.27 region |
|---|---:|---:|
| 0–10% | 124 | 124 |
| 10–20% | 66 | 66 |
| **20–50%** | **148 (44%)** | **0** |

So **44% of the shadow's flags came from the band A7.27 never observed**. That is the question the
blind pack was built to answer, and before answering it the honest expectation was that many were
false positives.

# 3. Evidence-state matrix

| | athlete SAT | programme SAT | acceptance | evidence | reachable outcomes |
|---|---|---|---|---|---|
| **A** | ✓ | ✓ | ✓ | MEASURED | any of the four |
| **B** | ✓ | ✓ | ✗ | PARTIAL | clear or `ACADEMIC_REVIEW` — **never `PRE_READ`**, the joint condition is unmet |
| **C** | ✓ | ✗ | ✓ | PARTIAL | clear if acceptance high; otherwise `INSUFFICIENT_EVIDENCE` |
| **D** | ✗ | ✓ | ✓ | PARTIAL | as C — no comparison exists, so no shortfall claim |
| **E** | ✗ | ✗ | ✓ | PARTIAL | as C |
| **F** | any | any | any | — | today's state for every institution: `test_policy` UNKNOWN, recorded in the reasons |
| **G** | ✓ | ✓ | ✓ | MEASURED, **discounted** | test-optional: the published average reflects submitters only, so the shortfall is overstated |
| **H** | ✓ | ✓ | ✓ | falls back to PARTIAL | test-blind: the comparison is **dropped, not discounted** — a score the institution does not read is not evidence about admission there |
| **I** | ✓ | ✓ | ✓ | MEASURED | conflicting — large shortfall, high acceptance: **clears** |

**The asymmetry is the load-bearing rule: a HIGH acceptance rate is adequate evidence that admission
is not an obstacle; a LOW one is never adequate evidence that it is.** Partial evidence may clear a
case and may never condemn one. Measured across the 56 runs: `ACADEMIC_REVIEW` was reached on a
missing acceptance rate **0 times**, and the concern set fired above 50% acceptance **0 times**.

No case was forced into the extreme flag to increase coverage — case S-07 is the proof: partial
evidence, a 43% acceptance rate, and the shadow returned `INSUFFICIENT_EVIDENCE` rather than reach.

# 4. `test_policy` — the future contract

Not built. Not scraped. No institution value invented.

| value | effect on the reading |
|---|---|
| `REQUIRED` | the published average is the enrolled body's; the shortfall is evidence at full weight |
| `OPTIONAL` | the average reflects **submitters only** and is biased upward, so the shortfall is overstated and should not on its own reach the strongest outcome |
| `BLIND` | the institution does not read the score; the comparison is **dropped**, evidence falls back to acceptance alone, and `PRE_READ` becomes unreachable on test evidence |
| `UNKNOWN` | today's state for all 2,406 programmes |

**Are `TEST_FLEXIBLE` / `NOT_REPORTED` necessary? On this evidence, no** — and adding them would be
inventing distinctions before they have consequences. `TEST_FLEXIBLE` (submit a score or something
else) behaves as `OPTIONAL` for our purpose: the average is still submitter-biased. `NOT_REPORTED`
is not a policy at all — it is `UNKNOWN` with an explanation, and the existing `academic_rating_source`
pattern already shows how to carry that as provenance rather than as an enum member. **Four values.**

**Why this field is the highest-value single collection.** Today a missing `sat_avg` is
indistinguishable from a test-blind institution — 528 men's and 363 women's programmes publish no
average, and we cannot tell which of those are cases where the score would not have mattered anyway.

17 deterministic cards, selection by predicate, no school named in any rule, codes hash-ordered,

`3767d84` before the sealed file was opened.

# 6. Disagreement analysis

Three disagreements, all the same shape:

| card | shortfall | acceptance | shadow | short of the −350 cut by |
|---|---:|---:|---|---:|
| Johns Hopkins | −303 | **6%** | `ACADEMIC_REVIEW` | 47 |
| Rice | −303 | **8%** | `ACADEMIC_REVIEW` | 47 |
| Trinity (TX) | −316 | 26% | `ACADEMIC_REVIEW` | 34 |

**Cause: A — bad boundary.** Not B (all three are MEASURED, nothing was missing), not C (the blind
reasoning is explicit and the gradient is monotone), not D (no inconsistency: the review answered
YES to −303 at 8% and NO to −360 at 81%, which is coherent).

The specific defect is that the shortfall cut is a **constant** while the evidence says it should be
a **function of selectivity**. Observed, not fitted: at 6–8% acceptance a 303-point shortfall
warranted a question; at 43% it took 421. The blind write-up reached this independently — *"the
shortfall which should trigger a question is not a fixed number: it should be smaller the more
selective the institution."*

**Not tuned here.** Moving the cut to −300 would fix all three cases and would be exactly the
case-by-case tuning §9 of the brief forbids. It is recorded as a design finding for the next phase.

**And it may not need fixing at all**, which is the more interesting result: every one of the three
was already caught by `ACADEMIC_REVIEW`. The two-level output places all 13 YES cards in a concern
state and all 4 NO cards outside one. **The error is in level assignment, not in detection.**

# 7. False positives — the number the brief asked to watch

**Zero, on both the single-level and two-level readings, including seven cards in the band the
boundary was guessed for.**

The structural reasons, each measured rather than argued:

- The concern set fired above 50% acceptance **0 times in 5,600 programme-runs**. The
  high-acceptance clearance is doing the work.
- `ACADEMIC_REVIEW` was reached on a missing acceptance rate **0 times**.
- `PRE_READ` is unreachable without MEASURED evidence, by construction.
- The two clearance cards the blind review called out — 81% and 95% acceptance with a −360 shortfall
  and a +8 — both cleared.

**The honest limits.** n = 17. I designed the boundary and judged the cards, so this is not
independent validation and is not presented as it. What it is: an out-of-sample test of the one
parameter that was a guess, on cards chosen to break it, which it survived.

---

# 8. False negatives

Three on the single-level reading, zero on the two-level. All three are top-10 recommendations
(ranks 1, 3, 6), which is where a miss costs most. On the two-level reading the residual risk is not
detection but **salience** — an `ACADEMIC_REVIEW` label on a rank-1 programme at 6% acceptance may
not carry the weight it should.

The union fires on **10.1 programmes per top-100** on average (4.0 review + 6.0 pre-read), rising
with athletic ability and falling academic profile, and never above 50% acceptance.

# 9. Product-facing language

Uncertainty-aware, no probability, no claim of rejection.

**MEASURED → `PRE_READ_RECOMMENDED`**

> **Academic pre-read recommended.** Students enrolled here average around 1498 on the SAT — about
> 400 points above your score — and the university accepts roughly 14% of applicants. Recruited
> athletes are assessed differently from general applicants and a coach's support can change this
> materially, so it is worth asking about academic admissibility before building a plan around this
> programme.

**MEASURED → `ACADEMIC_REVIEW`**

> **Worth raising early.** Students enrolled here average around 1416 — about 300 points above your
> score — at a university accepting roughly 26% of applicants. That is a gap worth mentioning to the
> coach in your first exchange rather than later.

**PARTIAL**

> **Limited admissions evidence.** We hold an acceptance rate for this university but no enrolled
> test average to compare with your record, so we cannot say how your academic profile sits here.
> If academics matter to you, ask the coach what they look for.

**UNSCOREABLE**

> **No admissions evidence on file.** We hold no test or acceptance data for this university, so we
> can say nothing about academic admissibility either way — in either direction.

**`NO_MATERIAL_CONCERN`**: show nothing. Y2 of the blind review is explicit that flagging an
81%-acceptance institution "would waste the athlete's credibility with a coach on a non-question,
and would train them to ignore the flag when it matters."

**Refused throughout:** "will not get in", "academically impossible", "ineligible", "unlikely to be
admitted", and any percentage.

# 10. Architecture decision

| option | verdict |
|---|---|
| **A. shadow only** | **no longer necessary** — the flag separated perfectly on an adversarial set |
| **B. visible flag, no rank effect** | **justified, staged** |
| **C. extreme-tail Recruitability modifier + flag** | **not yet** |
| **D. extreme-tail Pursuit modifier after gates + flag** | **not yet** |

**B is justified, with staging.** Operator-facing first: the operator can discount a wrong flag and
is the right person to catch a systematic error on real athletes. Athlete-facing only after an
**independent** human review — because the current validation has one evaluator who also designed
the boundary, and a flag shown to an athlete about their own academic record is not a low-stakes
piece of UI.

**Ship the two-level output, not the single level.** It is the reading with zero errors in both
directions.

# 11. Is any rank effect justified yet? — **No**

- 17 cards is not calibration, and the brief says so itself.
- **Recruited-athlete latitude remains completely unknown** (A7.27 §12: no pre-read record, no
  admissions outcome, no coach guidance anywhere in the database).
- A7.25's finding stands: amplifying a signal that has not been validated against outcomes made
  recommendations worse, twice.
- A flag is reversible by the reader. A rank effect is not, and at 10.1 programmes per top-100 a
  tail modifier would move real lists.

**Order of operations: make it visible, collect what happens, then decide.**

# 12. Coach Recruiting Intelligence — the learning loop

Two object families, matching the FACT / SIGNAL split the evidence engine already enforces.

**Athlete-specific evidence** — FACT about one athlete-programme pair, append-only, each with
`observed_at`, source and a verbatim quote where one exists:

`ACADEMIC_INFORMATION_REQUESTED` · `TRANSCRIPT_REQUESTED` · `TEST_SCORE_REQUESTED` ·
`COACH_SAYS_ACADEMICS_SUFFICIENT` · `COACH_SAYS_ACADEMICS_BORDERLINE` · `PRE_READ_REQUESTED` ·
`PRE_READ_SUBMITTED` · `PRE_READ_POSITIVE` · `PRE_READ_CONDITIONAL` · `PRE_READ_NEGATIVE` ·
`ADMITTED` · `DENIED`

**Programme-level historical admissions intelligence** — SIGNAL about a programme, derived and
re-derivable, never hand-edited:

`test_policy` · `coach_gpa_guidance` · `coach_test_guidance` · `pre_read_exists` ·
`pre_read_window` · **`observed_supported_band`** — how far below the enrolled body a supported
recruit has actually been admitted, with a count and a date range.

**The distinction has to be structural, not conventional.** An athlete-specific FACT is evidence
about that athlete and expires with the cycle; a programme-level SIGNAL is evidence about the
institution and accumulates. Collapsing them would let one coach's remark about one athlete become a
standing claim about a university.

**How it replaces the generic boundary.** `observed_supported_band` is exactly the quantity A7.27
§12 said we cannot learn and §11 above says must not be invented. Once a programme has enough
events, its own band replaces the generic rule for that programme; until then the band is UNKNOWN
and the generic boundary applies — which is the same "unknown is not a number" discipline §3 already
enforces. This is the natural home inside Coach Recruiting Intelligence: the system that learns
which coaches reply is the system that learns which coaches can carry an academic recruit.

Not implemented. Concepts only.

# 13. Smallest next step

**Not a boundary sweep.** The two-level output has zero errors in both directions, so sweeping the
shortfall cut would be tuning against 17 cards — the thing §9 forbids and the thing A7.22 already
proved worthless.

The smallest justified step is **a level-assignment pack**: 12–15 cards confined to shortfalls
between −250 and −400 across acceptance rates from 5% to 45%, asking one question — *is this "raise
it early" or "check before you plan"?* That is the only question the 17 cards left open, it is
cheap, and it directly tests the one hypothesis the disagreements produced (that the shortfall
warranting a question shrinks as selectivity rises).

**In parallel, and independent of it: start collecting `test_policy`.** It is one public field per
institution, it is the difference between "no evidence" and "evidence that would not have mattered",
and nothing else in this phase is blocked on it.

# 14. Unresolved operator decisions

1. **Operator-visible now, or wait for independent review?** §10 recommends operator-first. The
   counter-argument is that one evaluator who designed the boundary is thin grounds for any visible
   surface, even an internal one.
2. **Where does the flag live in the product?** On the recommendation card, in the outreach draft,
   or only in the operator's review queue. A flag in the athlete's email draft is a different
   product decision from a flag in a list.
3. **Does a flagged programme still get outreach?** A pre-read *is* a form of outreach, so "flagged"
   may mean *contact differently* rather than *contact later*.
4. **Who is asked to collect `test_policy`, and at what coverage is it useful?** Partial coverage
   still helps, because the value is per-institution and not aggregate.
5. **Recruited-athlete latitude** — still the load-bearing unknown, now with a defined home
   (`observed_supported_band`) and a defined collection path (§12), but no data.
6. **The two Phase-3D follow-ups**, still open from A7.26: Emmanuel (MA) and New England College
   men's CCC against women's GNAC; women's Little East / GNAC conference completeness.
