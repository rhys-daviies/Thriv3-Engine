# A7.38 — preregistration

**Written and committed BEFORE any candidate was run and before any post-tournament number existed.**
Production scoring baseline `0ae0399`. Baseline behaviour: A7.37 (`d6b8c1f`).

---

## 0. The single question

A7.37 is frozen. Readability propagation, the measured-zero guard, horizon visibility, the 2030
refusal, the F0 coverage correction and the explanation codes are **baseline, not under test**. The
tournament runs strictly **after** component scoreability has been decided, and asks one thing:

> when exactly one half of Playing Pathway is scoreable, what should the pathway be?

`pathway = 0.6·competition + 0.4·rotation` when both score is **unchanged in every candidate**.

## 1. Why the candidate space is closed

The measured defect is a **location shift**: dropping competition replaces a term whose pool median
is 0.600 with one whose median is 0.437 (men's) / 0.515 (women's), so any cell losing that half falls
by ≈ `0.6 × (median rotation − median competition)`. A7.37 predicted −0.098 and measured −0.096.

Given the blend is fixed by §2, exactly four structural responses exist:

| | response | candidate |
|---|---|---|
| 1 | renormalise onto the survivor | **A** (control, = A7.37) |
| 2 | fill the missing half with a **fixed** value | **B** |
| 3 | fill it with an **evidence-derived** value | **C** |
| 4 | refuse | **D** |

Rescaling a component to make the halves commensurate would change the both-known value, which §2
forbids. **There is no fifth option, so no Candidate E is preregistered** — adding one after results
would be exactly the post-hoc variant §8 prohibits.

## 2. Candidates — frozen

### A — renormalisation (control)
`competition-only → competition`; `rotation-only → rotation`. Grade PARTIAL. This is shipped A7.37.

### B — weight-preserving anchor
```
competition-only:  0.6·competition + 0.4·ANCHOR
rotation-only:     0.4·rotation    + 0.6·ANCHOR
```
**`ANCHOR = 0.5`, frozen.** Both components are *constructed* on [0,1] — competition as
`1/(1+pressure/0.75)`, rotation as a clamped p10→p90 placement — so 0.5 is the midpoint of the scale
itself. A7.22 preregistered the same reasoning for REF-MID: *"both are constructed on [0, 1], so 0.5
is a defensible semantic midpoint that cannot drift with pool composition."*

**It is a fixed point, not a pool statistic**, so it cannot smuggle in sex, division, position or
programme strength. That is its entire defence. **No other anchor will be tried.** If 0.5 fails, B
fails.

### C — evidence-derived prior
Same shape as B, with the anchor replaced by the **pool median of the missing component**, computed
over cells where that component *is* scoreable, excluding the cell under evaluation's own programme.
Two sub-variants, both frozen:

- **C1** — one median per (sport, component).
- **C2** — one median per (sport, position, component).

Deterministic; nothing is tuned. **C must additionally survive §6 of the brief**, and is rejected on
semantics if the prior is not stable across sex, division, position, strength band and horizon, or if
it turns out to encode programme strength.

### D — refuse (conservative control)
Either half unscoreable → **pathway UNSCOREABLE**. Because pathway is a REQUIRED component,
Opportunity becomes unscoreable and the programme falls to LIMITED_DATA. **This is not a reason to
reject it in advance** — the consequence is measured, at every horizon, before it is judged.

## 3. Primary acceptance — completeness bias

The exact A7.36/A7.37 matched analysis: division × position × rotation quintile, cells with ≥3
observed rows, fully readable versus ≥50% unreadable, entry 2028, both sports.

A candidate **passes** when, on **both** sports:

1. `wins / (wins + losses)` lies in **[40%, 60%]** — the window A7.37 preregistered and missed; **and**
2. `|median delta| <= 0.05`.

> **Condition 2 exists to stop condition 1 being gamed by mass ties**, which §9 of the brief warns
> about. 0.05 is anchored on the A7.36 decile table: the smallest step between adjacent pathway
> deciles is ≈0.06, so a bias below 0.05 cannot move a cell a full decile. Ties are reported as their
> own column and never counted as wins.

**For any candidate where the comparison has no data** — D produces no pathway for the incomplete
side — the result is reported **NOT APPLICABLE**, never as a pass.

## 4. Regression conditions — every candidate must hold these

| id | condition |
|---|---|
| **R1** | **horizon**: at entry 2030, 0% of cells at competition `1.000 MEASURED`; pathway interdecile range `p90 − p10 >= 0.20` where pathway is scoreable |
| **R2** | **Saint Joseph's**: competition remains UNSCOREABLE, and the result must truthfully convey *rotation strong, returning competition unknown* |
| **R3** | **genuine thin roster**: a fully-readable, depth ≤ 1 group with few returners still scores above a comparable crowded one, MEASURED |
| **R4** | **no missing-data-as-opportunity**: incomplete cells must not regain a systematic advantage (`median delta <= +0.05`) |
| **R5** | **coverage**: Opportunity scoreable share and Pursuit RANKED share reported per sport per horizon; a candidate that makes a large share unrankable must justify it |
| **R6** | **preference**: playing priority 1→5 must remain neither inert nor dominant — top-100 churn strictly `> 0` and `< 100` |
| **R7** | **isolation**: Recruitability, Financial, Candidate G, majorFit, admissions and both eligibility modules bit-identical |
| **R8** | **strength guard**: top-100 median programme strength reported; movement `> 5` points is a diagnostic warning to be investigated, never a selection reason |

## 5. Measurement set — fixed now

Men's and women's separately. Entry years **2027, 2028, 2029, 2030**: pathway value percentiles,
MEASURED / PARTIAL / UNSCOREABLE, rotation-only / competition-only / both shares, maximum share,
Opportunity scoreable %, Pursuit RANKED %, LIMITED_DATA count. Plus the matched analysis (§3), the
Saint Joseph's case, the thin-roster controls, the V3-C / W3-C priority-5 classifications at **both
2027 and 2028**, and the priority 1→5 sweep.

**Priority-5 classification** keeps the A7.36 classes and splits the thin one, per §13:

- **SUPPORTED_THIN_ROSTER** — few returners, `readableShare === 1`, competition scoreable, `depth <= 1`
- **UNSUPPORTED_THIN_ROSTER** — thin, but `readableShare < 1` **or** `depth >= 2` **or** competition refused

> At entry 2028 every cell is depth 2, so the split is expected to be degenerate there. **That is why
> 2027 is measured as well**, and the prediction is recorded here rather than discovered later.

## 6. Anchor / prior stability — the test C must survive

For B and C, the anchor is recomputed within each stratum of: sex · division · position · programme
strength quartile · entry horizon. **A value claimed to be neutral is rejected if it moves
materially across strata.** Threshold, frozen: a spread of more than **0.10** across the strata of
any one dimension disqualifies a global prior, because that exceeds the 0.05 bias budget in §3 and
would mean the "prior" is carrying stratum information.

B's anchor is a constant and passes this by construction; the test is reported for it anyway, so the
contrast with C is visible rather than asserted.

## 7. Selection rule

A winner requires **all eight** of the brief's §20 conditions. Tie-break: **the simplest semantics
with the fewest invented assumptions.**

> Recorded in advance because it will matter: `coverage.js` chose renormalisation deliberately and
> says so — *"the alternative … would treat an unmeasured component as a zero, and that is the
> neutral-prior defect wearing the opposite sign."* **B and C would make Playing Pathway the only
> place in V2 that imputes a missing component.** That is an architectural inconsistency and counts
> against them at the tie-break, though it does not disqualify them outright: A7.37 showed
> renormalisation has a measurable cost, and consistency is not a reason to keep a defect.

**If no candidate clearly passes, the answer is NO WINNER**, production stays on A7.37, and no
candidate is tuned afterwards.

## 8. Implementation

Only a clear winner is implemented, exactly as written above, and the **entire tournament is re-run
against the implemented code**.

## 9. Database drift

The A7.37 drift persists and is unchanged (men's `colleges` 1159, the same 60 V1 fields). It is
**held constant**: every candidate is measured in one session against this same database, so all
comparisons are candidate-vs-candidate. **No shared data is modified in this phase**, and no snapshot
difference is attributed to a candidate without the stash-isolation check A7.37 used.

## 10. Declared in advance

- No candidate is selected because it produces stronger schools, better churn, or nicer lists.
- `THIN_ROSTER_EFFECT` is **not** assumed to be bad; the supported/unsupported split exists precisely
  because A7.37 showed most of it rests on readable evidence.
- If B and C both pass the numbers, B wins the tie-break, because a fixed midpoint invents less than
  a fitted prior.
- If A passes, A wins outright — it is already shipped and invents nothing.
