# A8.0 — baseline freeze: what was measured

Companion to `A8.0-preregistration.md`, which holds the design. This holds the
evidence. Verdict: **VALIDATION_DESIGN_REVIEW_REQUIRED** — the baseline froze
cleanly and is usable for five of the six acceptance categories; one coverage
decision is owed before the evaluative phase can assess the sixth.

## The 7B separation, proved rather than assumed

The question was not "has the shared database moved" but "can what 7B is about
to write change a matchmaking answer". Those are different questions and only
the second one matters.

Method: the two `STAGED` batches were replayed onto a **copy** of the corpus —
7B itself was never touched, and no promotion was run — and the full baseline
was rebuilt from both corpora and compared cell by cell.

| universe | cells | differing | rank moves | value moves | state moves |
|---|---|---|---|---|---|
| SUPPORTED | 9,794 | **0** | 0 | 0 | 0 |
| UNSUPPORTED | 2,690 | 1,042 | **0** | **0** | **0** |

The SUPPORTED digest `adf92496…` is identical across both. The 1,042
unsupported differences are refusal reasons becoming *more precise* —
`NO_ROSTER_ON_FILE` → `NO_CLASS_LABELS` / `NO_READABLE_POSITIONS` — because
those programmes now have a roster and still cannot be ranked. None gains a
rank, a value or a state.

The surprise worth recording: NJCAA programmes are not excluded because they
lack rosters. Giving them 5,004 roster rows left all 288 unsupported men's
programmes exactly where they were. It is the **absent eligibility rule** that
holds them out, which is the honest reason and the durable one.

## What V2 reads, and what 7B writes

V2's entire database surface is four query sites in
`server/lib/v2/poolContext.js` over three tables. `shared/matching/v2/`
contains no database access at all.

| table | V2 reads | 7B writes | overlap |
|---|---|---|---|
| `colleges` | yes | yes | **real** — `active`, `division`, `conference` |
| `roster_players` | yes | yes | **real** — scoped today to NJCAA/USCAA |
| `recruiting_arrivals` | yes | derived from rosters | indirect |
| `coaches` | **no** | yes | none |
| `athletics_domains`, `programme_membership_periods`, `refresh_*` | no | yes | none |

`coaches` is separated by construction. V2's "Coach Recruitability" is a layer
name; `recruitingRules.js` states that no coach reply, offer or outreach
response is held by the model.

The two overlaps are real, so they are **measured, not remembered**:
`server/scripts/a8CorpusGuard.js` takes the digest twice, over the two
universes separately. SUPPORTED moving invalidates the baseline. UNSUPPORTED
moving is expected whenever 7B lands two-year data.

## The structural tests were shown to fail

Twelve deliberately broken artifacts were built, one per failure mode, and each
was caught by its own test: unsupported leakage, rank gaps, order inversion,
out-of-bounds scores, `Infinity`, a RANKED cell missing a layer, a mismatched
`missingLayers`, a returned `ASSUMED` grade, a LIMITED_DATA cell given a score,
a duplicated programme, a dropped cell, and a person-level field. A
preregistered blocker test that has never been seen to fail is an assertion
about itself.

## The open decision

`intended_major` is `null` for all ten reference athletes, so `majorFit` —
weight 1.2, binary ±0.40/−0.60 — returns `notApplicable` for every one of the
12,484 cells. **Acceptance category 5 cannot be assessed for major fit.**

It is closable: 2,298 of 2,627 programmes (87.5%) carry `notable_majors`, so a
declared major would exercise the component rather than merely produce
refusals. The brief forbids altering a frozen athlete profile and requires a
new athlete to be justified first, so this is reported rather than decided.

Two narrower gaps, which limit coverage without blocking a category: every
athlete enters in **2028**, so the A7.37 horizon depth is exercised at exactly
one distance; and no athlete leaves the budget unstated, so the
`Undeclared` / `NEEDS_CONFIRMATION` path A7.48B proved at unit level is never
exercised end to end.
