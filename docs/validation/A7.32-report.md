# A7.32 — governing-body initial academic eligibility: source of truth

**Research and rule specification only.** No scoring, rank, Pursuit, Recruitability, UI or
eligibility code changed. Production remains `0ae0399`.

The sourced rule register is [`A7.32-eligibility-rules.md`](A7.32-eligibility-rules.md). This report
is the analysis built on it.

**Headline: four of seven associations are verified, three are not, and the single most consequential
finding is that the NCAA rule Thriv3 would most plausibly have implemented from memory — the
core-GPA/test-score sliding scale — no longer exists.**

| NCAA international process | **VERIFIED** |

| NJCAA | **UNVERIFIED** — HTTP 403 |
| USCAA | **UNVERIFIED** — HTTP 403 |

## The rule that would have been wrong

NCAA Division I Proposal **2022-34**, *Adopted Final*, effective **1 August 2023**, amended **Bylaw
14.3.1.1** to remove standardized test scores from initial eligibility entirely. The qualifier
standard is now **only** *"a minimum cumulative grade-point average … of 2.300"* in core courses.

**The historic sliding scale — core GPA traded against SAT/ACT — is gone for both Division I and
Division II.** It is the rule most likely to be recalled, it is the rule Thriv3's own `sat_score`
field would have invited, and encoding it would have produced confidently wrong eligibility
verdicts.

## Two research errors caught by the sourcing discipline

1. **A search summary asserted the 10/7 rule applies to Division II.** The Division II primary page
   does not state it. Discarded.
2. **`uscaa.org` is the United States CORPORATE Athletics Association** — a corporate
   track-and-field body. A domain-restricted search returned its rules on employee payroll status
   and alumni scoring. The collegiate body is the **United States Collegiate Athletic Association**
   at `theuscaa.com`. **A naive lookup would have encoded corporate track rules as collegiate
   academic eligibility.**

# 2. Structural findings that change the design

## Division III is not a weaker NCAA standard — it is *no* NCAA standard

> *"Division III schools set their own academic standards on campus, but the Eligibility Center
> certifies the athletics eligibility of Division III international student-athletes."*

| athlete | dimension A (admissions) | dimension B (eligibility) |
|---|---|---|
| **domestic D3** | the whole question | **does not exist** |
| **international D3** | still applies | **exists, and is certified by the Eligibility Center** |

This confirms A7.31's split from the primary source and adds something A7.31 did not anticipate:
**for an international D3 athlete both dimensions are live simultaneously**. That is a large share
of Thriv3's population — 26.4% of the men's pool is international, and D3 is the largest men's
division at 318 programmes.

## The NCAA and the NAIA measure different things

| | NCAA DI/DII | NAIA |
|---|---|---|
| GPA measured over | **NCAA-approved core courses only** | **overall high-school GPA** |
| core-course requirement | 16, with subject distribution | **none** |
| test scores | **not required** | **optional, but a usable criterion** |

**These are not two thresholds on one quantity. They are two different quantities.** A single
`gpa` field cannot serve both, and a single rule cannot be written across them.

# 3. Input gap matrix

Thriv3 holds four real athlete records; coverage figures are from them and are not a sample worth
generalising.

| rule input | Thriv3 field | status | note |
|---|---|---|---|
| overall high-school GPA | `players.gpa` | **AVAILABLE** (1 of 4) | serves **NAIA** directly; **does not** serve NCAA |
| **NCAA core-course GPA** | — | **SHOULD NOT BE SELF-CALCULATED** | computed only over NCAA-approved courses from that school's approved list; the Eligibility Center computes it |
| **core-course count / 16-course distribution** | — | **MISSING** | needs a course-by-course transcript and the school's NCAA-approved course list |
| **10/7 timing (DI)** | — | **MISSING** | needs per-course completion dates |
| SAT | `players.sat_score` | AVAILABLE (2 of 4) | **irrelevant to NCAA initial eligibility**; usable for NAIA |
| ACT | `players.act_score` | AVAILABLE (0 of 4) | same |
| high-school graduation | `players.graduation_year` | **DERIVABLE but not proof** (0 of 4 populated) | a year is not *proof of graduation*; the association requires a document |
| high school | `players.high_school` | AVAILABLE (3 of 4) | needed to locate the NCAA-approved course list |
| class rank (NAIA) | — | **MISSING** | one of the NAIA 2-of-3 criteria |
| **NCAA Eligibility Center ID** | **`players.ncaa_eligibility_id`** | **FIELD EXISTS, NULL for all 4** | already modelled, never populated |
| Eligibility Center certification status | — | **SHOULD NOT BE SELF-CALCULATED** | only the Center can state it |
| PlayNAIA status | — | **SHOULD NOT BE SELF-CALCULATED** | only the NAIA Center can state it |
| international credential evaluation | — | **SHOULD NOT BE SELF-CALCULATED** | the Center performs it |
| nationality / international status | `nationality`, `origin` | **AVAILABLE** (4 of 4, 3 international) | determines whether the international process applies |

**The decisive line in this table: every quantity the NCAA rules actually turn on is either MISSING
or SHOULD NOT BE SELF-CALCULATED.** Thriv3 holds a transcript GPA and test scores; the NCAA needs a
core-course GPA, a course inventory and completion timing, and does not use test scores at all.

**No field is added in this phase**, as instructed. The finding is that the existing
`ncaa_eligibility_id` is the highest-value field already present and entirely unused.

# 4. Result-state contract

The states must express what Thriv3 can honestly claim, which is **never eligibility**.

| state | meaning | when |
|---|---|---|
| **`NOT_APPLICABLE`** | no governing-body academic standard applies | domestic NCAA D3 |
| **`NOT_ESTABLISHED`** | Thriv3 lacks the inputs the rule turns on | **the default, and the common case** |
| **`REVIEW_REQUIRED`** | available evidence is materially inconsistent with the verified standard | e.g. an overall GPA far below the association threshold |
| **`NO_ISSUE_IDENTIFIED`** | inputs are present and none conflicts with the verified standard | rare today |
| **`RULE_UNVERIFIED`** | Thriv3 holds no verified rule for this association | **NJCAA, USCAA today** |

**Rejected: `VERIFIED_ELIGIBLE`.** Thriv3 cannot verify eligibility for any association and must
never imply it. **Absence of a detected problem is `NO_ISSUE_IDENTIFIED`, never eligibility** — and
even that wording is only defensible because it describes Thriv3's search, not the athlete's status.

`RULE_UNVERIFIED` is deliberately distinct from `NOT_ESTABLISHED`: one says *we do not know the
rule*, the other says *we do not have the athlete's inputs*. Collapsing them would hide which
problem is Thriv3's to fix.

## Certification language

Every output must name the authority. Drawn from the verified register, not invented:

- **NCAA DI/DII, and DIII international:** *"Eligibility is certified by the NCAA Eligibility Center.
  Thriv3 does not certify eligibility."*
- **NCAA DIII domestic:** *"Division III schools set their own academic standards. There is no
  NCAA-wide academic requirement to check."*
- **NAIA:** *"Eligibility is certified by the NAIA Eligibility Center (PlayNAIA)."*
- **NJCAA / USCAA:** *"Thriv3 does not hold verified eligibility rules for this association."*

# 5. The Old Dominion case, resolved from sourced rules only

Athlete GPA **1.0**; programme NCAA Division I; institutional acceptance rate 90%.

**What Thriv3 can establish:** the athlete's **overall** GPA is 1.0. Division I requires a
**2.300 core-course GPA** (Bylaw 14.3.1.1.3). Core-course GPA is computed over NCAA-approved courses
only and **may differ from the transcript GPA** — but a 1.0 overall is materially inconsistent with
a 2.300 core-course GPA.

**What Thriv3 cannot establish:** the core-course GPA itself; whether 16 approved core courses were
completed; whether the 10/7 timing rule was satisfied; whether the athlete graduated; whether the
Eligibility Center has certified anything.

**Verdict: `REVIEW_REQUIRED`.** Not "ineligible" — Thriv3 has neither the inputs nor the authority.

**Official process remaining:** NCAA Eligibility Center certification.

**Operator action:** *"The overall GPA on file is materially below the NCAA Division I core-course
standard of 2.300. Thriv3 does not hold the core-course record this rule is actually assessed on.
Confirm NCAA Eligibility Center status before relying on this programme."*

> **The 90% acceptance rate is irrelevant and does not appear anywhere above.** Dimension A returns
> NORMAL and is correct; dimension B returns REVIEW_REQUIRED and is also correct. This is the
> A7.30 reversal resolved from verified rules rather than from three models' recollection — and it
> lands in the same place, for a reason that is now sourced.

verification date on every rule; `UNKNOWN`/`UNRULED` as a first-class model rather than a fallback;
and no probability anywhere.

# 7. Regression specification (design only — no rules implemented)

The suite's purpose is to prove **dimensions A and B cannot contaminate each other**.

| # | case | dimension A | dimension B |
|---|---|---|---|
| 1 | clearly sufficient evidence, NAIA, GPA 3.5 | per admissions | `NO_ISSUE_IDENTIFIED` |
| 2 | clearly concerning, NCAA DI, overall GPA 1.0 | per admissions | `REVIEW_REQUIRED` |
| 3 | missing core-course information, NCAA DI, GPA 3.6 | per admissions | **`NOT_ESTABLISHED`** — a good GPA does not clear a rule assessed on a quantity we lack |
| 4 | international athlete, NCAA DI | per admissions | `NOT_ESTABLISHED` + Eligibility Center process required |
| 5 | **high admit rate + governing-body concern** | **NORMAL** | **`REVIEW_REQUIRED`** |
| 6 | **low admit rate + no governing-body concern** | **PRE_READ** | `NO_ISSUE_IDENTIFIED` / `NOT_ESTABLISHED` |
| 7 | NCAA DIII domestic | per admissions | **`NOT_APPLICABLE`** |
| 8 | **NCAA DIII international** | per admissions | **applies — Eligibility Center certifies** |
| 9 | NAIA, GPA 2.1, no class rank, no test | per admissions | `NOT_ESTABLISHED` (2-of-3 unevaluable) |
| 10 | NJCAA, any athlete | per admissions | **`RULE_UNVERIFIED`** |
| 11 | USCAA, any athlete | per admissions | **`RULE_UNVERIFIED`** |

**Invariants the suite must assert:**

- **Cases 5 and 6 are the contamination test.** Changing the acceptance rate must not move
  dimension B by any amount; changing the athlete's GPA must not move dimension A by any amount.
- **No dimension-B state may ever be `VERIFIED_ELIGIBLE`** — the value must not exist.
- **Case 3 must not return `NO_ISSUE_IDENTIFIED`.** A strong overall GPA is not evidence about a
  core-course GPA.
- **Cases 10 and 11 must return `RULE_UNVERIFIED`, never `NO_ISSUE_IDENTIFIED`.**

# 8. Rule-update governance

Every rule record carries: `association` · `division` · `rule_version` · `source` · `source_url` ·
`source_section` · `effective_from` · `effective_to` · `verified_at` · `verified_by` ·
`verification_method` · `supersedes` · `caveats`.

**Staleness detection** — three independent triggers, because each catches a different failure:

1. **Age.** Any rule whose `verified_at` is more than **12 months** old is `STALE`. Eligibility rules
   move on an annual legislative cycle.
2. **Cycle boundary.** Any rule whose `effective_to` has passed, or which has no `effective_to` and
   was verified before the current academic year began, is `STALE`.
3. **Source reachability.** A periodic check that every `source_url` still resolves. **This phase is
   the argument for it**: the NAIA bylaw page 404'd, the NCAA New Zealand page now redirects to the
   homepage, and two association sites returned 403. A rule whose source has vanished is not a
   verified rule any more, whatever its `verified_at` says.

**A `STALE` rule must degrade to `RULE_UNVERIFIED`, not continue to be applied.** Silent application
of an expired rule is how the sliding scale would still be in production.

# 10. Smallest next implementation phase

**Specify the rule records; evaluate almost nothing.**

1. Add `shared/initialEligibility.js` carrying the **four verified NCAA records** as data, in the
   `shared/eligibility.js` shape, with sources, verification dates and caveats. **Nothing
   imports it.**
2. Implement exactly **one** evaluable path: **NCAA DIII domestic → `NOT_APPLICABLE`**. It requires
   no athlete input, it is verified by direct quotation, and it is correct for the largest men's
   division.
3. Every other association/division returns `NOT_ESTABLISHED` or `RULE_UNVERIFIED` **by
   construction, not by calculation**.
4. Ship the regression suite in §7, including the contamination invariants.

This produces a correct, honest, shippable dimension B whose main content is a clear statement of
what Thriv3 does not know — which is the accurate state of affairs and is still a large improvement
on silence.

# 11. Operator decisions required

1. **Who obtains the NAIA bylaw text?** It is behind a 404 for automated fetch. One person with the
   2025-26 Official Handbook (p. 70 is cited by NAIA's own interpretations site) closes it.
2. **NJCAA and USCAA: obtain, or declare out of scope?** Both block automated access. NJCAA is 228
   men's programmes; USCAA is 11. The cost/benefit differs sharply between them.
3. **Should Thriv3 collect `ncaa_eligibility_id`?** The field already exists and is null for every
   athlete. It is the single highest-value academic input available, because it is the key to the
   only authority that can answer dimension B.
4. **Should intake collect a core-course transcript?** This is the input the NCAA rules actually turn
   on. It is a materially heavier intake ask and a product decision, not an engineering one.
5. **Do the DI academic-redshirt and DII partial-qualifier categories still exist?** Needs the fact
   sheets, which would not retrieve.
6. **Who owns annual rule re-verification**, and against the three staleness triggers in §8?
7. Carried forward: `test_policy` ingestion, the ten other test files with the latent path defect,
   and the two Phase-3D follow-ups from A7.26.
